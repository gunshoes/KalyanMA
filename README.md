# In-memory и файловая база данных книг

## Описание проекта

Проект представляет собой простую систему управления данными для хранения информации о книгах.

В четвертой лабораторной работе к in-memory реализации добавлены файловые реализации базы данных:

- JSON-файловая база данных;
- CSV-файловая база данных.

Данные могут храниться на диске и не теряются после завершения работы программы.

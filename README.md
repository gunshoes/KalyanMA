# In-memory база данных книг

## Описание проекта

Проект представляет собой простую in-memory базу данных для хранения информации о книгах.
В третьей лабораторной работе программа переработана с использованием объектно-ориентированного подхода.

Данные хранятся в оперативной памяти во время работы программы.
